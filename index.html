How to use it

Desktop: each section has its own vertical scroll. Hover over a section and use the mouse wheel or trackpad to scroll only that section.

Reordering: drag the dotted handle. A blue line appears between songs to show exactly where the song will be placed when you release it.

Add or remove sets: use + Add Set in the toolbar. Use the minus button in a section header to remove that section; its songs are moved safely to Shelf.

iPhone/iPad: press and drag the dotted handle, or use the ↑/↓ buttons and the Move menu.

Multiple songs: choose Select Multiple, tap the songs, then drag the handle on any selected song. The whole group moves together and keeps its order.

Lyrics layout: each song can use the normal scrolling view or a two-column view. Use the layout button while viewing lyrics, or choose the layout in Edit Song.

Lyrics alignment: use Left, Center, or Right in the lyrics view. Alignment is remembered separately for each song and also appears in Edit Song.

Saved setlists: Save Setlist stores a snapshot of the current section structure and song order, including added sections such as Set 3. Loading a saved setlist restores that arrangement without deleting songs you added later; newer songs are moved to Shelf.

Online song search: Add Song can search Apple’s public iTunes catalog and import title, artist, album, year, genre, and duration. Internet is only needed for the search itself; your setlists and lyrics remain local and work offline.

Backups: Export Backup regularly. Import restores your songs, active setlists, and saved setlist snapshots on another device or after browser data is cleared.
